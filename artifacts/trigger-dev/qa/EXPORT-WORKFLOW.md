# Reproducible final export

Run with Python3.11+ (Pillow/numpy for frame comparison) and ffmpeg/ffprobe. Paths below are relative to this qa directory. Primary media must not exist before the encoder runs. The raw MOV is never modified.

```sh
python3 validate-receipts.py --source ../media/nova-trigger-dev-original.mov --recorder-log recorder.log --plan edit-plan.json --receipts reviewed-clicks.json --output-dir mapping-v1
python3 edit-recording.py ../media/nova-trigger-dev-original.mov edit-plan.json ../media/nova-trigger-dev-silent.mp4 scratch-empty-legacy.mp4
python3 add-click-sounds.py --source ../media/nova-trigger-dev-silent.mp4 --cues mapping-v1/final-cues.json --output ../media/nova-trigger-dev-clicks.mp4 --report sound-verification.json
python3 verify-click-export.py ../media/nova-trigger-dev-clicks.mp4 mapping-v1/final-cues.json decoded-audio.json --fps 30
python3 check-decoded-frames.py
```

EDL clicks is intentionally empty: the first editor's legacy mono effect is not used. Its silent video is muxed with the unchanged approved stereo effect by add-click-sounds.py. Empty legacy movie is scratch only, deleted after validation. The resulting silent and click versions must have identical encoded video stream hashes. Original session/operator ledger, per-click visual response notes, exact frame EDL and mapping are retained. Scratch PNG/JPG evidence is regenerated by source frame indices when needed and pruned after complete QA.

Frame comparison requires raw review extracts in frames/: for each frame in frame-indices.json, decode that original source frame and scale to1512×888 only for comparison. Final movies remain3024×1776. check-decoded-frames.py extracts matching output frames and compares68 click/response pairs outside only the measured debugger row and codec-edge allowance.
