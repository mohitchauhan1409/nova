# Rehearsal checklist

## Local preparation

- [ ] Build this branch, reload the unpacked extension, and start a fresh Nova conversation.
- [ ] Confirm local profile data uses `sites.mastra.json`.
- [ ] Ensure Nova has no Mastra key, provider key, repository token, or billing credential.
- [ ] Hide notifications and unrelated tabs; prepare no secret values for screen entry.

## Live prerequisite pass

- [ ] Confirm hostname exactly equals `projects.mastra.ai`.
- [ ] Re-observe organization, credits, plan, project list, and any environment context.
- [ ] Capture the no-project or blank-route state once; do not retry it in a loop.
- [ ] Confirm whether inspecting the project entry point can be done before OAuth or object creation.
- [ ] Identify exact visible prerequisite labels without starting Connect, Import, or Create.
- [ ] Confirm that $0 credits does not permit a safe hosted run; do not purchase or test.

## Readiness-flow rehearsal

- [ ] Verify Nova asks only for missing public repository metadata and environment-variable names.
- [ ] Verify Nova never asks for a key value, repository token, or provider credential.
- [ ] Verify Nova produces a written plan when the UI cannot safely hold an unsaved draft.
- [ ] Verify the cursor never activates Connect, Import, Create, Deploy, Publish, billing, or credential controls.
- [ ] Verify the closing summary states the observed blockers and that nothing was deployed or spent.

## Conditional telemetry rehearsal

- [ ] Proceed only with an existing accessible project and designated synthetic trace/log.
- [ ] Read project, environment/deploy, and time range before filtering.
- [ ] Verify no new telemetry is generated by agent, workflow, tool, prompt, scorer, or evaluation runs.
- [ ] Verify visible evidence is separated from diagnostic hypotheses.
- [ ] Verify sensitive prompt/tool content and unrelated records stay hidden.

## Abort conditions

Abort the affected scene if it requires credits, purchase, OAuth, repository connection, key/secret entry, project creation, deployment, publication, hosted execution, a plan upgrade, or access to unrelated telemetry. Also stop on a blank route, ambiguous context, missing task-owned evidence, or repeated unchanged action. Report the prerequisite rather than broadening scope.
