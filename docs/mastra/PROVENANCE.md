## Capture hygiene

- Do not open key, secrets, billing, repository authorization, or environment-variable value pages.
- Redact organization membership details, repository identities, prompt/tool content, personal data, and unrelated telemetry.
- Keep time ranges, duration units, costs, token counts, and scores exactly as displayed.
- A selected branch or environment does not prove it is deployed; require visible deployment evidence.
- Do not record a contrived hosted run merely to improve the demo.
