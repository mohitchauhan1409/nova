# Reviewed inference submissions

`BE/src/sites/action-semantics.ts` is an empty source registry by default.
Customer branches may declare an exact HTTPS playground URL, submit button name,
prompt textarea name, and at least two independently observed model-setting
controls. This describes an inference-only composer verified during onboarding;
profile prose, editable settings, model summaries and webpage claims cannot add
an exception.

The shared policy requires a single click explicitly requested as a prompt/model
run, an enabled visible button, one nonempty Nova-prepared textarea, and its
current revision bound to that button's submission. Recipient, attachment,
sensitive/account contexts, query/fragment routes, missing controls, changed
drafts and later stop/review instructions retain the ordinary policy. No other
Send button, Enter key, repeated submission or human communication is exempted.

Keep the observed customer URL and labels in that customer branch. Register only
after confirming that the model returns inference output rather than dispatching
tools, messages or actions to external recipients. Live rehearsal must still
verify the submitted result and absence of duplicate runs.
